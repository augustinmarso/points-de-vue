# LA SÉANCE « POINTS DE VUE », ÉCRAN PAR ÉCRAN
# ------------------------------------------------------------------
# Ce fichier se modifie directement sur GitHub : bouton crayon en haut à droite,
# puis bouton vert « Commit changes ». Le site est à jour une à deux minutes après.
#
# Chaque écran commence par un mot entre crochets. L'ordre du fichier est l'ordre de la séance.
# Pour retirer un écran : supprimez ses lignes. Pour en déplacer un : coupez-collez ses lignes.
# Une ligne qui commence par # est un commentaire, l'appli ne la lit pas.
#
#   [accueil]              la salle d'attente (QR code, code, participants connectés)
#   [texte] petit titre | grand titre | phrase
#   [5 secondes] image     une affiche montrée 5 secondes   (ajoutez « | étape 1 » pour la rattacher à une étape)
#   [jeu] question         question avec une bonne réponse : « + » devant la bonne, « - » devant les autres
#   [scores]               les réussites de chacun au jeu
#   [étape 1]              l'écran de titre d'une étape (1, 2 ou 3)
#   [question] question    question à choix : « - » devant chaque réponse
#                          ligne « réponses : une » ou « réponses : plusieurs »
#   [note] question        note de 1 à 5, avec les lignes « de : » et « à : »
#   [a ou b] question      comparaison de deux affiches, avec « affiche a : » et « affiche b : »
#   [mission] [photos] [tests] [palmarès] [fin]   l'atelier en binômes et la fin
#
# Lignes possibles sous une question :
#   étape : 1                      (1, 2 ou 3 : donne la couleur et le titre de l'étape)
#   affiche : affiches/nom.jpg     (l'affiche montrée à côté de la question)
#   précision : une phrase sous la question
#   noir et blanc : oui            (l'affiche passe en noir et blanc)
#
# Les images sont dans le dossier « affiches » du dépôt.
# ------------------------------------------------------------------
