    Enregistrer sur le site

    Pour écrire sur le site, cette page a besoin d'une clé GitHub (un « jeton »). Elle reste dans ce navigateur, sur cet ordinateur.

    1. Ouvrez la création d'un jeton GitHub.
    2. Accès au dépôt : seulement « points-de-vue ». Permission « Contents » : lecture et écriture.
    3. Copiez le jeton et collez-le ici.

    Sans jeton : le fichier est copié, vous le collez à la place de l'ancien dans seance.txt sur GitHub.
